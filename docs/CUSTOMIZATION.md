# Customization

Use roles such as lantern, doorway, and ceiling so timing is independent of device IDs. Assign discovered IDs before live playback. Copy original bundled tones or provide your own audio file. Cue timing is seconds from timeline start; backend startup/network latency is not sample-accurate synchronization.

Scene cues resolve through named Govee JSON profiles. Experimental captured scenes retain their model/firmware limitations. Restoration covers reported power/color/brightness, not an opaque scene that a device cannot report.
